# shokunin-godot-2d — game-dev-2d

**2D game production, verified by executable headless fixtures.**

Loop, input, physics, scenes, camera, UI, levels, juice, export
readiness — on Godot 4.7.2 headless. If it did not run, it is not
claimed.

This is a **shokunin lane** of the [shokunin fleet](https://github.com/VeigaPunk/shokunin).
Canonical name: `game-dev-2d-shokunin`. Rank: **shonen**.

## The craft

- Fixtures under `corpus/fixtures/` (seeded from
  games-engine-mechanics r15; provenance in `corpus/knowledge/seed.md`).
- `run_battery.py` is the executable census: named arms, receipts,
  mutation rejection, source-contact planes.
- Demand context (`~/Projects/gamez/research/`) is read-only.
- Domain source trees are read-only. This lane writes its own corpus
  and reports.

A passing battery measures the named property (input lattice, physics
step, scene load, …). It is not a ship review, a juice-taste verdict,
or a store submission.

## Province

Owns: 2D game production verified by executable headless fixtures on
Godot 4.7.2.

**Refuses:** engine/editor source mutation; publishing or store
submission; asset rights clearance; harness/evidence auditing;
narrative canon (lore — contested scope is reported, not absorbed).

See [`PROVINCE.md`](PROVINCE.md).

## Start here

```sh
python3 corpus/fixtures/run_battery.py --help
```

Reports cite invocations of the form:

```sh
python3 corpus/fixtures/run_battery.py --godot /usr/bin/godot
```

Use the Godot binary that `SKILL`/reports pin (4.7.2 headless). A
different editor version is a different experiment.
