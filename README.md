# shokunin-godot-2d

**2D game production, verified by executable headless fixtures on
Godot 4.7.2.**

Lane name: **game-dev-2d-shokunin**. A **shokunin lane** minted and
trained under the [shokunin](https://github.com/VeigaPunk/shokunin)
skill.

**Wiki:** [lane overview](https://app.devin.ai/org/veigapunk/wiki/VeigaPunk/shokunin-godot-2d?branch=main)

## Domain

From `PROVINCE.md`: loop, input, physics, scenes, camera, UI, levels,
juice, export readiness — each claimed only when a headless fixture
executes it.

Sources (read-only):

- corpus fixtures under this repo (seeded from games-engine-mechanics
  r15; provenance in `corpus/` seed notes)
- `~/Projects/gamez/research/` as demand context
- Godot 4.7.2 headless runtime

Writes only this repository and its own reports. Domain source trees
are read-only. Engine/editor source is never mutated here.

## What it refuses

Publishing or store submission; asset rights clearance; harness /
evidence auditing; narrative canon
([lore](https://github.com/VeigaPunk/shokunin-world-bible) — contested
scope is reported, not absorbed). 3D production is
[game-dev-3d](https://github.com/VeigaPunk/shokunin-3d-engines). Audio
content is [audio](https://github.com/VeigaPunk/shokunin-game-audio).
