No assignment to `button_pressed`, `set_pressed*`, callback invocation, or `toggled.emit()` appears. The toggled callback only appends its received bool and sets the Label. On that code-review evidence, transitions and receipts are not manually manufactured.

Disconnected mode verifies unchanged state and `[]`/`Ready`. After release and a frame, both modes verify the next checked state; connected additionally verifies receipt count/order and Label (`On`, then `Off`), while disconnected again requires no receipts and `Ready`. The loop's `prior` is advanced only after those observations.

No intervening code intentionally changes focus. It does not re-check focus after each edge; adding that would make focus retention explicit, but I found no source path that transfers focus, and this omission alone does not falsify the edge evidence.
