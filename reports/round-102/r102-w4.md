Measured conclusions:
1. **Pack bytes are NOT path-dependent.** Carrying either run's import cache to a *different* path reproduced that
   run's sha **byte-identically** (cmp 0, both runs). This refines r101's LAW "Pack bytes are root-path dependent"
   (`reports/round-101/r101-adjudicator.md:130`) and E0-spec's "the exported `.scn` embeds a path-dependent hash"
   (`reports/round-101/r101-E0-spec.md`): the drift source is **import-cache generation**, not the path.
2. **The drift is exactly one 4-byte id** regenerated at every fresh import: B and D are two fresh imports at the
   *identical* path and they differ from each other; each fresh import yields a new value.
3. **Warm-warm byte stability holds** at the same path (B == C, cmp 0), consistent with the in-battery
   `byte_diff_count=0` assertion.

## 6. Verdict — the stability baseline the new r102 rows must match

- C1's zero-variance claim over the 12 r101 export_prod rows is **9/12 true, 3/12 false** as literally stated;
  the 3 exceptions are all the same mechanism (one per-import scene id), not host noise, not bound drift.
- Baseline the new export_launch rows MUST match:
  1. Byte-exact cross-run pins are allowed only for import-cache-invariant tokens (magic, entry counts, names
     digests, stable entry sizes, exit codes, refusal-class strings) — that is what the 9 identical rows pin.
  2. Artifact sha256 / archive byte totals may be pinned only (a) in-process within one warm cache
     (`equal_to_sample1=true byte_diff_count=0` pattern), or (b) across paths if the *same import cache dir* is
     carried (measured cmp-0 twice). They MUST NOT be pinned across fresh builds/roots.
  3. A new row that pins an embedded-binary/PCK sha across roots will be red-by-construction; the same applies to
     `bytes=` totals of exported archives.
- Cross-reference for the C1 executors: `reports/round-101/r101-E0-spec.md` already left sha/bytes trailing fields
  unpinned for this reason; the r102 launch matrix should carry the same discipline, and any *new* sha pin needs a
  warm-cache (or carried-cache) demonstration to be claimable.
