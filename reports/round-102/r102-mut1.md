Two modes, both executable:

  project, `/var/tmp`), forges it four ways, launches everything with the row launch
  shape `[artifact] --headless --quit-after 5`, and applies each check class:
  `naive = rc==0 and marker once`; `elf = first 4 bytes == \x7fELF`;
  `size = bytes >= stock template bytes`; `strong = naive and elf and size`.
* **fixture attack** (default; `--no-attack` disables): splices one env-triggered
  substitution into a *scratch copy* of each landed `export_launch*.gd` right after
  its export call (anchor must match exactly once or the splice refuses). With
  `EXPORT_LAUNCH_FORGE` set, the freshly exported binary is copied aside (backup
  lands in my scratch forge dir, not the fixture's dir) and the forged artifact is
  copied onto the pinned path — the fixture's own predicate then judges the forgery.
  The repo fixture is never written.

## 4. Minimal repair for the orchestrator (proposal — I edited no fixture)

1. **ELF magic guard** (kills the crafted sh wrapper; the assignment's minimum):
   after export, before structure checks, read 4 bytes:
   `if FileAccess.get_file_as_bytes(bin).slice(0, 4) != PackedByteArray([0x7f,0x45,0x4c,0x46]): _fail("not_elf")`.
   s02 can emit it as a receipt field (`elf_magic=true|false`) and add it to its
   mismatch predicate. Measured: crafted sh wrapper's first16 =
   `23212f62696e2f73680a7072696e7466` → fails; real export
   `7f454c4602010100…` → passes.
2. **Prefix identity** (kills the crafted ELF wrapper too): compare the artifact's
   first `template_bytes` bytes to the stock template (hash both; ~73.5 MB read,
   ≈0.2–0.5 s — s01 embed arm currently ~4 s against an 8 s bound). The stock
   template path is already located by s01/s02 (`_template_path`).
   Residual unknown: a genuine template copy with a fabricated pack payload would
   pass both (1) and (2); only a pack-content check or the boot itself separates
   that [inference — not measured].

## 5. Counterfactuals / discrimination evidence

* Control (no splice): genuine exports pass all three fixtures → the substitutions,
  not the harness, caused every rejection/acceptance (observation).
* Unpadded wrapper: rejected by both explicit fixtures (`artifact_size_invalid`,
  `receipt_mismatch`) → the rows are not trivially marker-only; the gap is
  specifically fabrication of size+trailer (observation).
* Standalone matrix: ELF-magic and size checks each catch exactly the class the
  other misses; together they reject all four forgeries (observation).
