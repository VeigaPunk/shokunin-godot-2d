## 4. Clause matrix (observed classification of the same bytes)

| clause (direct-execution replica) | A genuine | B success | C spoof | D shallow |
|---|---|---|---|---|
| `weak_merged_refusal` — refusal text in stdout+stderr → refusal | True | False | **True** | True |
| `weak_stderr_refusal` — refusal text in stderr → refusal | True | False | **True** | True |
| `rc_anchored_refusal` — `rc==1` and text → refusal | True | False | **False** | True |
| `rc_marker_class` — refusal: rc1+text+no marker; success: rc0+marker once | refusal | success | **success** | refusal |
| `rc_empty_stdout_refusal` — rc1 and stdout empty and text | True | False | **False** | True |
| `exact_block_refusal` — rc1, stdout empty, stderr == A block byte-for-byte | True | False | False | **False** |

Reading: **every text-only clause accepts the spoof as a refusal** (A and C indistinguishable),
while every rc/stdout-anchored clause rejects it (`rc_anchored=False`, class `success`). D shows the
residual: rc+text anchoring alone cannot separate a shallow rc=1 faker; the exact-block clause does
(D's 2-line block ≠ A's 4-line block). A byte-exact forger that copies all 4 lines defeats all
transcript-level clauses — that is the receipt-origin blindness boundary (r63/r101-mut2 class);
the remaining barrier is artifact provenance (sha/magic/size — mut01/crit1 territory).

Battery-row-level replicas over the same bytes (merged `classify_process` / strict `classify_streams`):

| arm | row exit0+marker merged | row exit0+marker streams | row exit1+refusal merged | row exit1+refusal streams |
|---|---|---|---|---|
| A genuine | False | False | **True** | False |
| B success | True | True | False | False |
| C spoof | True | False | **False** | False |
| D shallow | False | False | True | False |

[obs] C cannot satisfy a row whose `expected_exit` is 1 (`code == expected_exit` fails) — the
battery row is rc-anchored by construction. C does satisfy an exit-0+marker row (the launch really
succeeded) under merged classification; if a success row uses strict `classify_streams`, the foreign
stderr line rejects it (policy choice: launch hygiene vs stream purity). The refusal text lives on
stderr, so an `exit1+refusal` **streams** row with the signature on stdout can never pass — that
row shape is unusable for this class.

## 5. In-engine stage (the layer `export_launch.gd` will classify from) [obs]

Scratch-only `probe.gd` (in `/var/tmp/r102-mut2/proj/`) copies the `export_prod.gd:287-295` idiom:
`OS.execute("/usr/bin/sh", ["-c", "exec > <log> 2>&1\n" + body])`; nested output never echoed.
Command: `godot --headless --path /var/tmp/r102-mut2/proj --script res://probe.gd -- --arm=<arm>`.

```
# --arm=genuine (861 ms, outer rc 0)
ROW arm=genuine nested_exit=1 refusal_seen=true marker_seen=false
CLASS arm=genuine text_only=true rc_anchored=true rc_marker=refusal exact_block=true
FIXTURE_STYLE arm=genuine naive_text_pass=true anchored_pass=true

# --arm=spoof (1683 ms, outer rc 0)
ROW arm=spoof nested_exit=0 refusal_seen=true marker_seen=true
CLASS arm=spoof text_only=true rc_anchored=false rc_marker=success exact_block=false
FIXTURE_STYLE arm=spoof naive_text_pass=true anchored_pass=false
```

This is the trap in one line: **`nested_exit=0` with `refusal_seen=true`**. `nested_exit` is the
`OS.execute` return of the nested process (rc anchor); a fixture arm that prints only a
text-derived `class=mainpack_refusal` would emit its PASS for the spoof, while an arm that also
requires `nested_exit==1` cannot.

## 6. Findings

**F-M2-1 (target, measured — MEDIUM class-contract):** the refusal class is spoofable by a
successful launch that writes the refusal text to stderr; text-only classifiers (merged or
stderr-only) classify the spoof as a refusal on byte-identical-to-genuine text. rc/stdout anchoring
(rc==1, marker absence, empty stdout) rejects it. At the battery layer the outer row is already
rc-anchored (`classify_process` requires `code == expected_exit`); the exposure is the **nested**
classification inside the launch fixture and any stderr-text-only token. The required discriminator
is the nested rc (and/or empty nested stdout), not the text.

**F-M2-2 (byte-exactness, measured — LOW but would break a pin):** r101 prose quoted the refusal
without backticks (`r101-crit5.md:120`, `r101-scr1.md:43` show `--main-pack` unquoted); the actual
bytes wrap it: `` `--main-pack` `` and the hint line wraps `` `disable_path_overrides=no` ``.
A pin copied from prose will never match. Pin the byte-exact line (§3) or the backtick-free
substring `was specified on the command line, but this Godot binary was compiled without support for path overrides. Aborting.`

**F-M2-3 (boundary, measured — disclosed):** a shallow rc=1 faker with the 2-line text passes
`rc_anchored` and `rc_empty_stdout`; only exact-block pinning rejects it. A forger reproducing the
full 4-line block defeats any transcript clause; provenance pins (binary sha/size/magic — mut01 and
crit1 attack-1 class) are then the only barrier. `refusal_seen` alone is never sufficient.

## 7. Row recipe for the C1 launch matrix (line-pairs for orchestrator/E0/E3)

1. `export_launch_s03` refusal arm: run the stock template binary with
   `--main-pack <abs>.pck --quit-after <n>` through `_run_logged`; emit
   `nested_exit=%d` from the `OS.execute` return (`export_prod.gd:624` pattern) and
   `nested_stdout_bytes=%d` from the log (or `marker_seen=false`).
   PASS condition inside the fixture: `nested_exit==1 AND refusal_seen AND nested_stdout_bytes==0`.
2. CASES pinned signature must include the rc-derived token: `nested_exit=1` (byte-anchored to the
   PASS line). Never pin `refusal_seen=true` alone or the text alone.
3. If pinning the text, use the backticked byte-exact first line from §3 (or the safe substring in
   F-M2-2). The hint line and `at: setup (main/main.cpp:1892)` are additional genuine-only tokens
   (the trace is engine-source-position pinned; a shallow faker must forge it too).
4. Embed/success row: merged classification (`rc==0` + marker once) is adequate and accepts a
   successful launch even with foreign stderr text (C → True, correct). If strict
   `classify_streams` is chosen, note it rejects such a launch (C → False); s02's derived-boolean
   style (`exit`, `frames`, `marker_lines`) already avoids this by construction.
5. Do not pin pack sha (per-run drift at constant 1976 B, §3); size/magic/census as usual.

### 7a. Live-target audit (`export_launch.gd`, landed mid-seat) [obs]

The landed fixture's refusal arm (`corpus/fixtures/export_launch.gd:329-338`, `_arm_probe`) emits
via `_emit` (`:118-119`) the line:

`PASS export_launch refusal rc=%d class=%s hint=%s log_bytes=%d` with
`class=path_overrides_disabled iff ref_text.contains("compiled without support for path overrides")`,
`hint=disable_path_overrides_no iff ref_text.contains("disable_path_overrides=no")`; `rc` is the
`OS.execute` return of the nested `./probe.x86_64 --headless --main-pack <pck> --quit-after 3`.
The same field shape is emitted for `embed_refusal` (`:271-279`: embedded binary + a nonexistent
`none.pck`). Measured here for that arm's shape: embedded binary + `--main-pack <nonexistent>` →
rc=1, stdout 0 B, stderr = the **identical 265-byte block**
(sha256 `785a6ba9162e8c9dc7fce07fbf129bec30a30de29c992d938b37eaffa867ad28`, byte-equal to A);
the refusal precedes pack lookup, so the pack path need not exist.

Consequence for CASES registration: the emitted line carries the rc anchor, but the fixture fails
on nothing — `_emit` prints unconditionally, so **the row's pinned substring is the only
discriminator**. Pins must include the rc token (self-consistent with F-M2-1's spoof open line):

- spoof-safe: `PASS export_launch refusal rc=1 class=path_overrides_disabled hint=disable_path_overrides_no`
- spoof-open: any pin starting after `rc=` (e.g. `PASS export_launch refusal class=path_overrides_disabled`)
  — the spoof emits `rc=0 class=path_overrides_disabled hint=disable_path_overrides_no …`.
- `log_bytes=` is scratch/root-dependent (export_prod precedent) — pin only a derived-stable value.

## 8. Verdict and bounds

**Complete for the mandate.** A refusal-class spoof with a genuinely successful launch is
**REJECTED** iff the refusal clause anchors rc (and/or empty stdout), and **ACCEPTED** by every
text-only clause — measured on real exported binaries and reproduced in-engine at the exact
`OS.execute` layer the fixture will use.

Bounded / not measured ([unk] where so):
- `run_battery.py` never run (hard rule 1); no CASES row exists yet for this arm; clause shapes
  are verbatim replicas of live HEAD bytes (`§2`), executed on real capture bytes.
- `export_launch.gd` landed mid-seat and is audited post-hoc in §7a; `export_launch_s03.gd` (E3)
  was still absent at seat close — its planned arm should carry `nested_exit`/`rc` per §7.
- The spoof models a foreign stderr producer (wrapper/shield around the real binary). An
  `LD_PRELOAD`-style interposer into the real binary was not attempted; the measured mechanism
  (fd2 write without changing rc) is the same.
- D and full-block forgery bounds are stated in F-M2-3; no claim is made that text pins can
  distinguish deliberate forgery.
- Fixture wall-time under the 8 s bound (export ~2.1 s + launch ~0.9–1.7 s) was not separately
  envelope-tested here (E0/crit5 domain).
