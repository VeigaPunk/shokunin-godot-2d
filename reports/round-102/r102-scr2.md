## Symptom and correction
`probe_timeout` FAILed both r101 battery runs. Stored bytes: `slow_clean_old_bound` `marker_observed=false` at
`elapsed=0.753` (= the bound) while the new and hold arms are green — the sole red conjunct is `old_rejects` (the
marker requirement). The r101 adjudicator ("`hold_open_new_bound` arm … deterministic host-state class",
r101-adjudicator.md:81-86) described hold_open's *expected pass shape* as the failure; `hold_rejects` is satisfied in
both runs and r62's actual descendant-pipe meta (`probe_descendant_pipe_eof`) PASSes in both runs.

## Root cause
`old_rejects` requires the fixture's first print (`TIMEOUT_PROBE: expected signature`, a direct `write(1,…)` in
`_initialize`, strace-confirmed) to reach the captured pipe before the short bound. That time is engine boot +
project load: ≈0.38-0.49s at the r26 calibration vs 0.51-0.90s measured 2026-10-18 across seven seats (the banner
itself lands at ~0.015s). The 0.75s constant was sized against the r26 host; once load pushed boot→marker past it,
the SIGKILL lands pre-print and the marker is absent from the kill-drain. At bound 0.75 today the arm was ~59% red
pooled (n=44 draws), 0/49 committed receipts ever missed r22–r79, and both outcomes occurred minutes apart on one
host — a race, not a class. Not capture loss (pre/post-kill byte accounting equal; CPython's second `communicate()`
returns the cumulative stream), not bound drift (constant unchanged since r26 commit 3e44ccb3), not expectation rot
(the statements are still true; the margin vanished — r22: "0.394s normal startup, leaving only ~0.356s margin … a
slow start can false-fail; no stability claim").

## The law
A marker-vs-bound conjunct is two-sided: `max(boot→marker) < bound < min(boot→clean exit)`. With a fixed in-script
delay both edges rise together under load, so a fixed bound near either edge is a coin flip. Size the bound inside the
measured window with recorded margins; re-measure the window whenever the host regime changes. Observed window
2026-10-18 across seats: [0.90, 2.06] (worst marker sample 0.898, n=19; quickest clean exit 2.06; own-run values
0.760-0.847 / 2.17).
