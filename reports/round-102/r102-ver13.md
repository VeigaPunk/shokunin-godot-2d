## 4. PCK v4 container (observed format; `parse_pck.py` receipts)

Header 112 B: `0x00` magic `GDPC`, `0x04` version=4, `0x08/0x0c/0x10` godot 4.7.2, `0x14` pack flags
(`0x2` = relative file base; **identical for full and patch packs**), `0x18` file_base u64 (=112),
`0x20` dir_offset u64. Directory at dir_offset: u32 count, then per entry: u32 path_len, path (relative,
no `res://`), pad4, u64 offset, u64 size, md5[16], u32 entry flags (`0x0` plain, `0x4` delta-encoded).
Empty pack: 112 B, `dir_offset=0`, no entries. Patch packs use the same container — no marker flag.
