## 0. Verdict

1. [obs] M1's literal attack (bare script wrapper printing the marker) is already
   rejected by the census pins (pinned `tail_magic` hex ≠ `47445043`) and by E2 s02's
   trailer pins. (A marker-printing bare wrapper still passes the pure `embed_boot` row —
   expected; the census row is the embed/self-containment discriminator, as the spec says.)
2. [obs] A **fingerprint-forged script** — a padded shell script that ends in `GDPC`,
   matches the genuine artifact's byte size, has a consistent `u64`/`GDPC` trailer with
   the pack region at the template boundary, and prints the exact boot receipt — is
   **accepted by every asserted clause of all three landed fixtures** (measured, §2/§3).
   The missing clause is the ELF head magic (`7f 45 4c 46`): no landed row reads it.
3. [obs] Pinning the head byte is safe and sufficient for the script class: a file that
   starts `\x7fELF` **cannot run** via the shell (measured rc 126, `cannot execute binary
   file: Exec format error`, zero stdout, under `/usr/bin/sh` (=bash) and bash); a file
   that runs is not an ELF. So `head4 == 7f454c46` (static) + the existing boot pins
   (behavioral) jointly kill every script shape I could construct.
4. → Row-requirement in §4 (add one pinned hex field; keep sizes unpinned if desired).

## 4. Row-requirement (orchestrator; exact edits to fold)

REQ-1 (required, minimal): every `export_launch` embedded-binary row must assert the
artifact's **ELF head magic on the same path it launches**, pinned as a hex field:

* `export_launch.gd` `_arm_embed` census: add
  `census.append("head_magic=%s" % _head_magic(bin))` (existing helper, hex-encodes,
  returns `missing` on unreadable);
  extend the E0-spec row pin to:
  `'PASS export_launch embed_census artifacts=1 sidecar_pck=0 tail_magic=47445043 head_magic=7f454c46'`
* `export_launch_s01.gd`: promote `elf_prefix_equal` (s01:323) from `_diag` into
  `_emit_structure` + `_structure_ok` (or add an asserted `head_magic` field = `7f454c46`).
* `export_launch_s02.gd` `_arm_embed`: add asserted `head_magic` (hex head4) to the
  predicate next to `trailer_gdpc`.

Why this and not size: [obs] "real size" is forgeable by padding (attacks B/E match the
genuine byte count exactly); the head byte is not, because a runnable script cannot
start `\x7fELF` (rc 126 measured on both shells this host has). The existing
`tail_magic`/trailer pins stay — they catch classes A/D and any truncated/footerless ELF.

REQ-2 (recommended, cheap): pin `bin_gt_template=true`-style boolean in E0's census
(measured root-stable: delta 0 across two roots for both my project and E0's fixture) —
kills D statically even when the sidecar is renamed away.

REQ-3 (optional hardening, closes class F): `template_prefix_ok=true` defined as
`sha256(artifact[0, T-1024)) == sha256(template[0, T-1024))` ∧ `u64@(T-1000) == R` ∧
`u64@(T-992) == P+12` (T = template size, located via the existing `_template_path()`
idiom). Label per-engine-layout; measured true on genuine, false on F.

[inf] With REQ-1 folded, the registered embed rows reject every script class measured
here (A/B/C/E) while genuine artifacts and D-rejecting behavior are unchanged; M1's
"(ELF magic or real size)" criterion is then satisfied by the ELF-magic arm.
