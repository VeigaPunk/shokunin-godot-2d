## 0. TL;DR (for the C1 `export_launch` rows)

- The refusal is one `ERR_PRINT` at `main/main.cpp:1892` (string literal at :1893–1894),
  selected by `#else` of `#if defined(OVERRIDE_PATH_ENABLED) || defined(WEB_ENABLED) ||
  defined(ANDROID_ENABLED)` (guard at :1867). Runtime `at:` line agrees: `main.cpp:1892`.
- `OVERRIDE_PATH_ENABLED` is defined by the build system iff
  `env.editor_build or not env["disable_path_overrides"]` (`SConstruct:1101-1102`);
  the option `disable_path_overrides` defaults to **True**, description "(export template
  only)" (`SConstruct:272-278`); `env.editor_build = env["target"] == "editor"` (`SConstruct:533`).
- Therefore: **editor builds always accept CLI path overrides; export templates built with
  defaults refuse them.** The stock official template on this host is a default build →
  refuses. Measured live, both directions (arms A/B below).
- The refusal is decided at CLI parse time, before any file resolution: a valid pack path
  and a nonexistent pack path produce **byte-identical** stderr (sha256 below).
- The stock template still runs the sanctioned non-CLI route: pack named after the
  executable, sitting next to it (arm C, marker + rc=7). The build flag gates the CLI
  override only — not project loading in general.
- **Environmental hazard for any template arm that can fail project load** (measured):
  the non-tools build calls `OS::alert(error_msg)` after printing the load error
  (`main.cpp:2130` ERR_PRINT, `:2132` alert), and `OS::PlatformLinuxBSD::alert` executes
  the first of zenity/kdialog/Xdialog/xmessage found in `$PATH` (`os_linuxbsd.cpp:104,163`)
  **and waits for it**. With zenity present, a `--headless` template run with no loadable
  project blocks on a modal dialog (>75 s observed; killed). Strip those 4 programs from
  PATH (or ensure absent): the alert falls back to `print_line` (`os_linuxbsd.cpp:165`)
  and the run exits rc=1 in ~10-20 ms (arm E′).

## 3. Which builds define the support

- `SConstruct:272-278` — `BoolVariable("disable_path_overrides", "Disable CLI arguments to
  override project path/main pack/scene and run scripts (export template only)", True)`
  → **default True** (override support OFF).
- `SConstruct:1101-1102` — `if env.editor_build or not env["disable_path_overrides"]:
  env.Append(CPPDEFINES=["OVERRIDE_PATH_ENABLED"])`.
- `SConstruct:533` — `env.editor_build = env["target"] == "editor"`.
- Net effect (source-derived): editor target → always defined; template target → defined
  only with `disable_path_overrides=no`. Official release templates use defaults → OFF.
- Web builds are exempt for `--main-pack` (`WEB_ENABLED` in the :1867 guard); Android is
  exempt only for packs inside the executable `assets` dir (:1868-1886). Not measurable on
  this host — **inference from source**; the linuxbsd arms are measured.
