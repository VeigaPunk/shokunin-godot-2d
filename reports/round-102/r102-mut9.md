## 4. Guard requirement for the orchestrator (export_launch rows)

**G-A (derivation).** The fixture's `extra` token MUST be computed as a whole-capture equality of
the captured run log against the expected grammar — all non-banner lines, in order, exact
multiplicity (marker once, `FRAME 1..N` once each, nothing else) — never as `frames != [1..N]`
nor by matching only expected lines. Measured: the naive form reads `extra=false` under A1–A3 in
the model, and the **landed S02 fixture still uses the naive form** (§3.1, fixture line 382), so
its receipt accepts the in-span attack as-is.

**G-B (row signature).** The row signature MUST include `extra=false` **and** an output-bytes
bound (e.g. `run_log_sha256=<16hex> run_log_lines=<n>` derived from the captured log bytes) plus
the frame vector. Marker-only / frames-vector-only / rc-only / naive-extra pins were measured to
accept A1–A3 (model matrix and the landed fixture).

**G-C (no filtered digest).** Do not let a digest computed over expected/filtered lines be the
only binding token (SF1 hole, measured invariant under all three attacks here).

**G-D (streams).** Battery `classify_process` merges stdout+stderr (`run_battery.py:1791`
signature `in output`); the measured foreign lines were stdout-only, but stderr-carried forgery
(r101-crit2 G5) remains — the launched-binary span should be asserted in stdout alone.

**G-E (newline discipline, r101 G6).** Byte comparison or an explicit
normalized-text policy; my captures are LF-only and the harness decodes text-mode.

**G-F (ceiling).** Whole-stdout-bytes closure binds the launched *process stream*; the residual
class is a fixture that prints a canned receipt without launching (fixture-byte/artifact-digest
binding, r101 G8 analogue). Out of scope for the row pin itself.
