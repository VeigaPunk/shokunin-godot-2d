## 1. Format facts (engine source, fetched; behavior re-measured locally)

Citations (fetched master; the host build is 4.7.2.stable — source is for mechanism, bytes are local):

* `core/io/file_access_pack.cpp` `PackedSourcePCK::try_open_pack()` — standalone: magic at offset 0. Self-contained: (a) `OS::get_embedded_pck_offset()`; (b) fallback at EOF: last 4 bytes must be `GDPC`, then `ds = u64` at `EOF-12`, pck start = `EOF-12-ds`.
* `platform/linuxbsd/os_linuxbsd.cpp` `OS_LinuxBSD::get_embedded_pck_offset()` — walks the ELF section table and returns the file offset of the section named **"pck"**.
* Instrument file: `core/io/pck_packer`-style header in the same file: V4 header = magic, version, ver_major, ver_minor, ver_patch, pack_flags, file_base(u64 @24), dir_offset(u64 @32), then directory at `dir_offset` (count u32, then entries: u32 path_len, path, u64 ofs, u64 size, md5[16], u32 flags); `file_base += pck_start_pos` at load.


| artifact | bytes | sha256 (first 16) | note |
|---|---|---|---|
| `linux_release.x86_64` template **T** | **73519416** | `d9f79ab89b5ae369` | stock template |
| sidecar `v1plain.pck` **P** | **2008** | `dd40ea2fee8f4f87` | embeds `=v1plain.x86_64` byte-copy of T |
| `--export-pack` `v1pack.pck` | **2008** | `dd40ea2fee8f4f87` | **identical sha to sidecar** |
| embedded `v1embed.x86_64` **E** | **73521432** | `bfa3f8c6254055d2` | `E − T = 2016`, **`E − T − P = +8`** |

* Re-export byte-determinism (warm, load ≈6): `v1embed2.x86_64` sha `bfa3f8c6…` = E; `v1pack2.pck` sha `dd40ea2f…` = P. Deterministic at this state.
* Embedded layout (observation, hexdump + directory parse): pck starts **exactly at T** (no pad; `GDPC` at 73519416). Last 12 bytes = `[u64 2004][47 44 50 43]` = payload length + `GDPC`; loader: pck start = `E-12-2004` = T ✓. Embedded payload = 2004 B (7 entries, same names/sizes/md5 as standalone): `file_base=104`, `dir_offset=1528`; payload ends with a 4-byte tail pad. Standalone: `file_base=112`, `dir_offset=1536`, no tail pad → 2008.
* ELF patch (observation): first T bytes of E are **not** byte-identical to the template — exactly 6 bytes differ at 73518416..73518425: template `d0 f9 3d 04 …` / `08 00 …` → embedded `38 d1 61 04 …` (= 0x0461d138 = **T**) / `e0 07 …` (= 0x7e0 = **2016**). That is the exported binary patching the ELF "pck" section header with (offset, size); `PLAIN_EQ_TEMPLATE` (non-embed binary is a byte copy).
* Caution for checks: the stock template itself contains **five** internal `GDPC` byte sequences (offsets 43122210, 43122294, 43122372, 43122515, 43295037) → a naive "grep GDPC" is **not** an embeddedness test. Use the EOF trailer magic and/or ELF "pck" section.

## 2b. Script-size sweep + a silent host-state corruption incident (11 shapes)

Sweep: `main.gd` varied by `const PAD := "A"*N` (compiles into `main.gdc`), export embedded + pack for N ∈ {0,1,2,3,4,5,6,7,9,13}; `E`, `P` measured on bytes. (Correction to §0: these exports ran *without* the private-tmpfs guard — one of 11 was silently corrupted.)

* **10/11 shapes healthy**: `E − T − P = +8` in every one, while `main.gdc` moved 332→336 and `P` moved 2024↔2040 → the +8 margin is stable under content-size change. Trailer checks (all 11): `ds` = payload length, pck start = T, count=7; data-head spot checks (`eg_0`, `eg_4u`): `ECFG`.
* **1/11 shape (N=4) corrupt, export rc=0**: `E − T = 1792` (`E − T − P = −232`); embedded payload 1780 B; directory entry `project.binary` **size=0** (healthy 235 B, data head `45 43 46 47` = `ECFG`); `dir_offset` 1304 vs healthy 1544 (−240). Boot: rc=**1**:
  `ERROR: Corrupted header in binary project.binary (not ECFG)` + `ERROR: Couldn't load file 'res://project.binary', error code 16.` + `ERROR: Error: Couldn't load project data at path "/var/tmp/r102-ver1/iso4". Is the .pck file missing?` + `at: setup (main/main.cpp:2130)`.
* Symptom class matches the repo's own documented packer failure (`corpus/fixtures/export_prod.gd:36-46`: fixed temp path `/tmp/tmpproject.binary-<rand>`, EDQUOT → 0-byte project.binary while export exits 0). Direct strace not captured → mechanism **inferred**, symptom **observed verbatim**.
* Counterfactual (host-state cause): same N=4 shape re-exported under `unshare -m --map-root-user sh -c 'mount -t tmpfs tmpfs /tmp && …'` → `E − T = 2032` (+8), `project.binary` 235 B, boot rc=0, frames 1..3, stderr 0. A plain re-export right after (quota recovered) was also healthy → transient, not content-dependent.
* Paired-artifact fragility: the `--export-pack` `pg_4.pck` exported seconds later was healthy (`project.binary` = 235). A cross-artifact size comparison can mix a corrupt embedded exe with a healthy pack.

## 3. s01 expected values — embedded binary launch + size lower bound

Positive run (copy **only** the binary to an empty dir; cwd has no project files, no `.pck`):

```
cd /var/tmp/r102-ver1/iso   # contains only v1embed.x86_64
env -i HOME=/var/tmp/r102-ver1 PATH=/usr/bin:/bin ./v1embed.x86_64 --headless --quit-after 2
```

* rc=**0**; stdout **122 B**: banner `Godot Engine v4.7.2.stable.official.ed1daf0bf` + blank + `VER1_READY marker=main` + `VER1_FRAME 1` + `VER1_FRAME 2`; stderr **0 B**.
* Same binary from a different cwd (`/var/tmp/r102-ver1`, binary via `./iso/v1embed.x86_64`) → rc=0, same marker/frames.
* Banner nuance (observation): exported binary reports `.official` (editor reports `.arch_linux`) — do not pin the editor's build tag on exported-binary rows.

Size relation (healthy, 20 observations on this host): `E − T = payload + 12` (12-byte EOF trailer `[u64 payload_len][GDPC]`), and `E − T − P = +8` (payload vs standalone pack differs only in alignment-driven bytes: `file_base`/`dir_offset` ≈8 B earlier, ≈+4 B tail pad). Independent r101 measurement: `reports/round-101/r101-crit5.md:122` `template+1864` vs 1420 B pck (+444). **But §2b shows `E − T − P` can be negative (−232) from a silently corrupt export at rc=0** → a bare size pin is not a safe s01 assertion. Recommended contract: (1) run the fixture's exports under a private tmpfs (`unshare -m --map-root-user … mount -t tmpfs tmpfs /tmp`, the pattern `export_prod.gd:36-46` documents) and/or assert the packed `project.binary` data head is `ECFG`; (2) primary evidence = launch receipt (rc=0 + marker + frames); (3) only then size check `E − T ≥ P` in the same warm state, with T read from the installed template at runtime (never absolute pins; cold/warm pack sizes differ — `reports/round-101/r101-planner.md:74-84`).

Self-containment check method (recommended, all steps measured):

1. `mkdir` fresh empty dir; copy the single embedded binary; assert no `*.pck` present (`ls`).
2. Run with a minimal env (`env -i HOME=… PATH=/usr/bin:/bin`), `--headless --quit-after N`, from that dir; assert rc=0 + marker + exactly `frames=1..N`; stderr empty (measured).
3. Counterfactual (proves the check discriminates): the same project's non-embedded `v1plain.x86_64` **alone** in an empty dir → rc=**1** (see §4).
4. Optional: cwd-independence run (measured above).

## 5. For the orchestrator / executor seats (derived contract)

* s01: rc=0 + marker on stdout, run as a single binary in an empty dir; guard exports with private /tmp (or check pbin `ECFG`) **before** asserting size; size check `E − T ≥ P` in the same warm state with runtime-derived T. Do not pin an exact `E − T − P` (env-shaped: +8 healthy, −232 host-corrupt).
* s02: `--quit-after N` ⇒ exactly frames 1..N, rc=0, `extra=false`, stderr empty (observed N=1,2,3,6). The frame receipt is the strongest guard: it catches the §2b corruption (rc=1) that a size check can miss.
* Both: exported-binary banner is `.official.ed1daf0bf`; frame tokens are load-invariant; do not pair with wall-ms tokens.

## 6. Unknowns / open

* Exact packer rule behind the healthy 4-B payload difference (embedded payload smaller than standalone) — observed shape: pre-data area 8 B earlier, tail pad consumes 4 B; margin +8 measured across 20 healthy observations, but other projects/states may differ (r101-crit5: +444).
* The §2b corruption's triggering write was not strace-captured; mechanism inferred from the repo doc + 0-byte entry symptom. /tmp showed 3.1 G free at seat start (`WRITE1M_OK`), so this is a per-user-quota class, not free-space.
* Upstream source fetched is `master`, not tag 4.7.2; mechanism confirmed by local bytes but line numbers may drift.
* Universality of `E ≥ T + P` for healthy exports is **inference** from the format argument + samples; keep it a guarded lower bound, never an equality.
