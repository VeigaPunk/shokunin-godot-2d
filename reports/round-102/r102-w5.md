## 2. Floor-gate plan — ready splice (the deliverable)

Insertion point: immediately after `run_battery.py:4080` (the r101 gate's

`if r["case"].startswith(("r101_seqfull_", "r101_ytrans_", "export_prod_"))` — an anchor that
occurs **exactly once** (the other `export_prod_` occurrence is inside `cases_integrity` at 4099).
Both splice artifacts were validated by `w5_floor_gate_splice.py --self-test` → 13/13 PASS,
`rc=0` (raw: `/var/tmp/r102-w5/w5-floor-gate-selftest.out.txt`), on byte-copies under
`/var/tmp/r102-w5/` (py_compile OK; the repo file is untouched; `--check` on the live tree
currently exits 2 `PRE-SPLICE`, anchor count 1).

```python
        # r102 W5: the export_launch_ family ships with no expected_errors
        # entries today (nested Godot output is redirected to scratch logs,
        # never echoed - the export_prod.gd evidence rule), so this gate is
        # vacuous-but-honest for it, carried so a future allowlist entry
        # under the prefix cannot die silently; same named-by-round /
        # covers-round-prefixes shape as r87-r101.
        "r102_expected_errors_all_matched": all(
            not e["dead_in_run"]
            for r in census_rows
            if r["case"].startswith(("export_launch_",))
            for e in r["entries"]),
        # r102 W5: export_launch_ family count floor - every registered row
        # ran (execution-loop splice defects) and the family is non-empty
        # (a full-family drop from CASES and results together still fires).
        # A partial drop with CASES and results shrunk together is invisible
        # here by construction; freeze --min-rows N when the row set lands.
        "r102_export_launch_count_floor": (
            sum(1 for r in results if r["case"].startswith("export_launch_"))
            == sum(1 for c in CASES if c[0].startswith("export_launch_"))
            >= 1),
```

`--min-rows N` swaps the comparison to `>= N),` (recommended once the row count freezes:
N=6 in the self-test → cell J true at 6, **false at 5** = partial-drop class fires).

What each clause catches (self-test cells, all with the spliced text's own AST-extracted
