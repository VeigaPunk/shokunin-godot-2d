- **[obs] Strongest case receipt:** variants 2–6 produced **byte-identical packs**
  (sha256 `b577a43f0d2ab556…` full `b577a43f0d2ab5565950196cc4bae2aa75d7bf3439c62bdbbb543f1206ee4da7`),
  and a repeat of variant 2 (project later also carrying `other.dat`) reproduced
  the same sha. Token case, dir case, and `res://` prefix therefore change nothing.
- **[obs] `.GD` asymmetry:** `case/g_up.GD` (52 B) is exported **raw** (no `.remap`,
  no `.gdc`) and rides along even with an empty include filter; lowercase
  `case/g_low.gd` compiles to `.remap`(37 B)+`.gdc`(157 B). One `.uid` per script
  is minted on disk and lands only when a token matches it (variant 10).
- **[inf] Model:** `all_resources` exports every engine-recognized resource
  (`g_up.GD` counts as script-class by extension, but only lowercase `.gd` compiles);
  `include_filter` additionally adds non-resources; `exclude_filter` removes any
  matched path (resource or added), all matches case-insensitive (`matchn`-like glob,
  `*` crosses `/`, `res://` stripped before match). Engine internals not inspected.
