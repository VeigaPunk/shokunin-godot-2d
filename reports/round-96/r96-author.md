### `r96b_id.gd` — the (path, slot) id law (14)

`seqA2`/`seqAB2` (same path → same id; path determines, order does not),
`seq2obj` (two PackedScenes, same path → same id), `twoext` (slot
prefixes `1_`/`2_`), `extother` (dep content irrelevant),
`extshift` (prior generator draws don't shift), `mint_two` /
`subsamepath` / `subcontent` (sub ids f(path), content-irrelevant),
`subextra{0,3}` (extra draws don't shift), `subsame` (same obj, same
path → same), `subpath` (**sticky hazard**: resaving one object to a
second path keeps the first minted id), `fingerB` (loaded-resource
`generate_scene_unique_id()` sequence reproduces across processes).

### `r96b_seq.gd` — byte determinism incl. ext resources (5)

`extseq` (three paths → three ids, masked sha stable), `extpin` +
`minimal` (**headline**: pinned bundle → raw sha256 stable across
processes WITH an ext_resource), `extbundle` (BUNDLE inlines as
sub_resource, raw sha stable), `extgen` (save↔generator interleave grid).

### `r96b_cache.gd` — deep cache lattice + threaded load (10)

`deep_reuse`/`deep_replace`/`deep_ignore` (shallow modes: top resource
per mode, external dep stays stale), `deep_repl_deep` (deps refreshed
in-place, identity kept), `deep_ign_deep` (whole graph fresh, old cache
objects untouched), `ignoredeep` (fresh scene carries path; child dep
still the cached one), `repl_uncached`, `reuse_delete`,
`reuse_delay` (2.5 s wall delay does not disturb the cache), `threaded`
(`THREAD_LOAD_LOADED=3`, get() returns the cached object, status resets).

### `r96b_var.gd` — variance surface (6 arms / 7 rows)

`rich` (unique_id is the ONLY byte variance on a 10-node scene with
shared/nested/local subs, persistent conns/groups, metas, fractional
floats — `sha_uonly`/`sha_u_sub` pinned; pinned-bundle `sha_raw`
pinned), `conn` (6 persistent connections serialize sorted-canonical),
`groups` (persistent groups serialize sorted), `meta` (metadata keys
keep insertion order), `lever` (no public Node `*_scene_unique_id`
setter), `idstat_breadth` + `idstat_u31_gate` (200 minted ids distinct;
all minted ids < 2^31; pinned ids ≥ 2^31 are **silently dropped** on
save; instantiate still works).

### `r96b_phase.gd` — no phase coordinate (10)

`ph{0,1,2,5,30}` + `pph{0,1,2,5,30}` — minted ext/sub ids, generator
draws, and pinned-bundle shas are identical whether the save runs after
0/1/2/5/30 physics or process frames.

### `r96b_seed.gd` — generator seeding (1)

`seedcheck` — a loaded resource's `generate_scene_unique_id()` sequence
reproduces byte-identically across processes (path-seeded); a same-path
REUSE load continues the same object's sequence (A≠B within process);
different path and fresh `new()` sequences differ.
