**L1 — a hand-written `[remap]` block resolves with NO import pass and NO `.godot/`.**
A fresh project containing only `project.godot`, `asset.png` (fake bytes), `asset.png.import`
(4-line `[remap]` naming an existing `path=`) and `gen/dest.tres`:

```

```
exit 0, stderr 0 B. [obs] So remap resolution is a *file-level* mechanism: `ResourceLoader`
reads the `.import` sibling and redirects. This is what makes the fixture cheap (one nested
child, no editor import pass, no texture import).

**L2 — `exists()` follows the remap; `uid` does not come from the remap.**
Same project, `uid_source=-1 uid_dest=-1` while `exists_source=true` and the load succeeds.
Adding a hand-authored `.godot/uid_cache.bin` (no import pass) yields
`uid_source=1311768467294899695`, `uid_text=uid://sxovuchqei7p` — so `get_resource_uid` is
served by the UID cache, not by `[remap] uid=`. [obs]

**L3 — the `.import` is re-read per load; `[remap] type=` does not gate the load.**
Rewriting `path=` in place between loads retargets live (`retarget_load_name=s03_other`), while
the *cached* instance keeps the original name (`cached_name_after_retarget=s03_dest`). Setting
`type="TextFile"` against a `Resource` destination still returns the `Resource` [obs].

**L4 — `uid_cache.bin` format is hand-authorable and it is authoritative.** [obs]
`<u32 count>` then per entry `<u64 id><u32 len><path bytes>`. 57-byte file, count 2:
`0x3a56d42ac08cdc73 -> res://recon1.gd`, `0x28048890477b779e -> res://tiny.png`; the second
u64 is byte-identical to what `get_resource_uid` returned (2883579814679902110). A
hand-authored 31-byte cache (`0x1234567890ABCDEF -> res://asset.png`) was read back verbatim.

**L5 — `CACHE_MODE_IGNORE` yields a fresh instance but leaves the cache populated.**
`reuse_default_identity=true reuse_explicit_identity=true replace_identity=true
ignore_identity=false has_cached=true`. [obs]

**L6 — the real-import gate.** For an *unimported* real `.png` (no `.import`), `exists=false`
and `load()` returns null with `ERROR: No loader found for resource`; after
`godot --headless --import --path .` (1 step, exit 0) the same probe is `exists=true`,
`load=(res://tiny.png):<CompressedTexture2D#…>`. [obs] The engine also writes `tiny.png.import`
(`[remap] path="res://.godot/imported/tiny.png-<md5>.ctex" uid="uid://bhc3ex23pjjs5"`) and
`.godot/uid_cache.bin`. Used only as recon — the fixture does not need an import pass (L1).

**L7 — engine `ERR_PRINT` output goes to stderr, not stdout.** [obs] `2>/dev/null` removed
every `ERROR:` line from the probes; the battery's `run_process_streams` keeps the streams
separate and `classify_streams` rejects any unallowlisted stderr line. This is the reason the
fixture stages a child process and redirects its output to a scratch log.

# 3. Defects found and fixed in this seat's own fixture

1. **`_fail` was fail-open.** `SceneTree.quit()` only sets a flag honoured *between frames*, so
   the first working revision printed `FAIL …` and then continued and printed `PASS …` on the
   same receipt with **exit 0** — the exact r103 "PASS is grammar-invisible" hazard. Fixed with an
   `_aborted` latch: `_fail` returns early, `_verdict` returns instead of falling through.
   Exit code is the fail-closed signal.
2. **`missing` arm asserted against a dict it never populated** (read `_observed` while the values
   come from window-scoped `_variant_value`); every assertion read `<absent>`. Folded the window
   values into `_observed` so `_verdict` asserts and prints from one source.
3. **`\u00ef`-style escapes corrupt a binary cache.** GDScript `"\u00ef"` round-trips through UTF-8
   as two bytes, so the hand-authored `uid_cache.bin` would have been malformed. Now built as
   `PackedByteArray` + `to_utf8_buffer()`; `_write_file` takes a `Variant` and uses `store_buffer`.
4. **`_get` collides with `Object._get(StringName)`** (parse error) — renamed `_value_of`.
5. **Child exit code is an unsound gate.** One run in ~40 (uidcache arm) had the child exit 1
   while its log held every correct key. The gate now binds the child's own terminal evidence
   (`CHILD <arm> done`) and reports the exit code only as a `RES_UID_S03_DIAG` line.
6. **A guessed value was wrong:** `ResourceUID.id_to_text(0x1234567890ABCDEF)` is
   `uid://sxovuchqei7p` (I had first written a different string); `id_to_text(0)` = `uid://a`,
   `id_to_text(-1)` = `uid://<invalid>`. Corrected from measurement.
