## 2. Repair pattern (already landed in `corpus/fixtures/export_prod.gd`, lines 30–51)

`export_prod.gd`'s own header records the root cause: 4.7.2's packer serializes `project.binary`
through a **fixed** `/tmp/tmpproject.binary-<rand>` path (strace-verified; `$TMPDIR` is **not**
honored). Under EDQUOT that write fails, the packer ignores the error, and stores a **0-byte
`project.binary`** while the export still exits 0 — the pack then cannot load its own settings
(`Corrupted header in binary project.binary (not ECFG)`). Its fix: run exports inside

```
unshare -m --map-root-user /usr/bin/sh -c 'mount -t tmpfs -o size=64M tmpfs /tmp || exit 97; <export>'
```

Independently confirmed by me: `OS.get_temp_dir()` returns `/tmp` even when `TMPDIR` is set
(`TMPDIR=…/tmp4 temp=/tmp`), so fixtures hardcoding `/tmp` can never escape the quota by env alone.

**Every measurement below was taken with that private-tmpfs pattern** (512M), plus `--root=` /
`--work=` overrides into `/var/tmp` where the fixture exposes one. All 11 fixtures were run 3×.

### s06 — genuine defects; RETIRE pending repair
Uses `/var/tmp` (so not purely environmental), and fails rc=2 on all 3 runs. Three distinct defects,

   (verified: 0 SCRIPT ERROR lines after patch).
2. **0-byte `project.binary`:** arms failed at
   `entry_row_7 got=project.binary|0|e3b0c442… expected=project.binary|114|b07db252…`. Fixed by the
   unshare/private-tmpfs pattern: `baseline`, `include-gd`, `include-txt`, `include-xyz` then PASS
   with pins matching r101-E6 exactly (`pck_sha256=22defedba9461cf7…` ×3, `count=12`).
3. **Two stale/wrong pins + a sort-order bug** (still failing after 1+2):
   - `exclude-png`: pin expects `.godot/uid_cache.bin|71|8f55f49823622ec5…`; measured
     `0f4e9d46cf34d4f7f1541dac8859c68e5c11fe64998170dc46a42c7248df96b3`, **identical in 3/3 runs**
     ⇒ stale pin, not non-determinism.
   - `exclude-gd`: `S06 FAIL reason=exclude-gd dropped=… expected the 4 script entries`. The code
     compares `_paths_of(...)` (which yields canonical **`path|size|sha`** strings) against a bare
     path list (`want2`), so it can never match; additionally `want2` is written `.gdc` before
     `.gd.remap`, while the fixture's canonical sort orders `alpha.gd.remap` before `alpha.gdc`.
   These two arms need re-pinning/re-coding, not just an environment fix.

**Recommendation for s06:** keep RETIRED this round (its `exclude_filter` claim is already covered by
the registered `export_prod_include_exclude_filter` row); a future round may adopt it after the
