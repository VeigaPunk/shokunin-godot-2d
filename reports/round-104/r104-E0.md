## Measured findings (observation unless labelled)

**API surface** (`/var/tmp/r104-E0/proj/p1.gd`, `p2.gd`):
- 12 methods: `add_id, create_id, create_id_for_path, ensure_path, get_id_path, has_id,
  id_to_text, path_to_uid, remove_id, set_id, text_to_id, uid_to_path`; const `INVALID_ID=-1`.
- `path_to_uid(path) -> String`, `uid_to_path(uid) -> String`, `set_id` returns void
  (inference from `p2.gd` parse errors: `argument 1 should be "int" but is "String"` on
  `has_id`/`id_to_text`; `argument 1 should be "String" but is "int"` on `uid_to_path`).
- Digit alphabet `0-9a-z` → 0..35 (`uid://0`=25, `uid://9`=34, `uid://a`=0, `uid://z`=25);
  `uid://` and `uid://aaaa` both decode to 0 and id 0 encodes back to `uid://a` (alias).
- `create_id()` is positive and ≤ INT64_MAX; `2 ** 63` **overflows** GDScript int64 to
  INT64_MIN (measured `-9223372036854775808`), so `>= 2 ** 63` is trivially true — an earlier
  draft's "minted ids ≥ 2^63" was a **false positive, retracted**; the overflow is now pinned
  as a fact instead.
- `create_id_for_path(p)` is deterministic but does **not** register; `ensure_path(p)`
  returns the path and registers nothing.

**Path/echo class** (`path` arm): `path_to_uid` on any path with no uid returns **the path
itself** (`res://project.godot`, an absent path, a freshly saved `.tres`) — a silent shape
trap. `uid_to_path` on an unknown/malformed/empty uid returns `""`.

**Collision classes** (`collide` arm): two ids → one path keeps **first** forward
(`get_id_path` on both) while reverse `path_to_uid` returns **last**; one id → two paths keeps
**first**; `set_id`/`remove_id` are silent no-ops on an unregistered id; on a registered id
`set_id` retargets and `remove_id` clears. Engine diagnostics: `unique_ids.has(p_id)` (add_id,
`resource_uid.cpp:164`), `!unique_ids.has(p_id)` (set_id/remove_id, `:178`/`:232`).

**Load-cache identity** (`cache` arm): load-by-path, load-by-path again and load-by-**uid**
all return the same object; that object's `resource_path` is the **source path**;
`has_cached` and `exists` are true for both path and uid forms; `get_resource_uid(path)` and
`get_resource_uid(uid)` both equal the registered custom id. A `.tres` saved to disk is **not**
auto-registered (uid echo + `get_resource_uid = -1`) yet loads fine.

**cache_mode busting** (`modes` arm): `REUSE`/`REPLACE`/`REPLACE_DEEP` keep object identity,
`IGNORE`/`IGNORE_DEEP` return fresh objects; a later load-by-**uid** still hits the path cache
(`uid_after_replace_same=true`, `uid_path_kept=true`) while `REPLACE` refreshes the *same*
object in place from disk. Complements `r96b_cache.gd` (which covers the deep modes and
threaded loading) on the *uid* axis.

**`.import` remap** (`import` arm): an editor `--import` child writes `.godot/uid_cache.bin`
and `tex.png.import`; the source-path load and the uid-text load then return the **same**
`CompressedTexture2D` and `ResourceLoader.exists(uid)` is true.

**Cross-process persistence** (`persist` arm): a hand-written 32-byte `.godot/uid_cache.bin`
(`u32 count=1, u64 id, u32 len, path`) is honoured by a **fresh process** — `path_to_uid`
yields the uid, `has_id` true, `get_id_path` = the path — with no editor and no `--import`.
Format decoded from a real `--import` cache: `u32 count` + per record `u64 id, u32 path_len,
path utf8` (83 B for 3 records).

**Missing-UID class** (`missing` arm): a freshly minted id is unregistered; `uid_to_path` on
it returns `""`; an in-range but unregistered uid (`uid://zzzzzzzzzzzzzzz`) likewise;
`ResourceLoader.load("uid://…")` on an unknown uid returns null with
`Condition "local_path.is_empty()" is true` + `Error loading resource`; `exists` false; id 0
encodes to `uid://a` and `has_id(0)` is false.

## Defects found and fixed during measurement (this seat)

1. **`cache` arm pinned a process-random id.** `get_resource_uid(uid_text)` returned a
   different 19-digit id each run → `PASS_LINE_DRIFT`. Replaced with an equality relation
   (`== custom`); 3 rounds now stable.
2. **`import`/`persist` child-spawn flake.** Under load the nested headless child starts with
   a null cwd (`ERROR: Parameter "getcwd(real_current_dir_name, 2048)" is null.` at
   `drivers/unix/dir_access_unix.cpp:739` → `Invalid project path … aborting`), so `--import`
   never runs. Measured 0/8 failures in a quiet loop (z9), so it is load-correlated and
   environmental, not an assertion. Added bounded retries (≤4) + a project-dir guard;
   `tries` is diagnostic-only (`R104 …` lines, never pinned). 8/8 green after the fix.
3. **Unallowlistable random diagnostic (avoided).** An earlier `collide` draft called
   `get_id_path()` on an id whose `set_id()` had been refused, producing
   `ERROR: Unrecognized UID: "uid://<random>".` — a per-process random string no allowlist
   entry can match (prefix entries need a trailing comma). The arm was restructured (rr.gd
   probe) so the line is never emitted; the remaining two stderr lines are constant.
4. **False positive retracted** — see the `2 ** 63` overflow note above.
