**D1. Family tokenizer (the diag-prefix regex, verbatim from the landed script):**

```python
FAMILY_RE = re.compile(
    r"^(?:R\d+[A-Z]*"
    r"|SEQ_(?:BEGIN|CENSUS|DONE|END)"
    r"|EXPORT_[A-Z0-9_]+_DIAG"
    r"|S03_DIAG"
    r"|(?:BUTTON|CHECKBOX|SLIDER|HEALTH_GAUGE)(?:_[A-Z0-9_]+)*"
    r"|OBSERVED|STALE|NAV_LATTICE_TEARDOWN_CRASH"
    r"|DESCENDANT_PIPE(?:_[A-Z]+)*"
    r"|SPONTANEOUS_CRASH_PROBE:"
    r"|FEATVEC|TEXPROBE|E6_S06_[A-Z]+"
    r"|DIV_S02_[A-Z]+|S03_MARKER|LAUNCH_S02_[A-Z]+"
    r"|EXPORT_(?:PROD|LAUNCH)_(?:MAIN|FRAME)"
    r"|arm=[a-z_]+|g_low|g_up|ei=-?\d+)(?=[\s=:]|$)")
```

**D2. Binding rule.** The matched token must be in the row's script set `fams[script]`
(frozen table); otherwise `DIAG_UNBOUND` (catches mut05 s2a). This is what a bare prefix
whitelist cannot do: `EXPORT_LAUNCH_DIAG` in a `controls/input_route.gd` row is foreign.

**D3. Key-vocabulary rule.** For a bound family, every bare-word `key=` token in the payload
must be in `vocab[family]` (frozen from r102); otherwise `DIAG_KEY` (catches mut05 s2b's
`forged=1`; `forged` ∉ {nested, root, userns_tmp_isolation, project, disk_uid, XDG_DATA_HOME}).
Value drift (run-scoped paths `…T212500…Z` vs `…T213443…Z`) is why this must be grammar+vocab,
never byte-pinned [obs: 20 rows drift on `root=`/`nested=`/`project=` values only].

**D4. Non-diag account classes (needed for a complete account; G0/G1 own the full spec):**
- banner `^Godot Engine v\d+\.\d+\.\d+` valid at index 0 only — else `BANNER_POS` (s1a/s1b);
- PASS strict `^PASS ` + per-case tag set + per-case count cap (`PASS_TAG`/`PASS_COUNT`; s3a/s3b/s4b/s4c; `\tPASS`/`PASS\t` fall through to `FOREIGN`; s4a/s4d);
- engine blocks: `ERROR: `/`WARNING: ` starts, continuation grammar (`at:`, `GDScript backtrace (most recent call first):`, `[N]` frames at 3/7/9 spaces, tab-led, `The following presets`, 8-space quoted, `Use …`); crash grammar (`handle_crash:`, `====`, `double free or corruption`, `/usr/include/`, `-- END OF … BACKTRACE --`, 4-space GDScript frames); per-case block caps → `ENGINE_ERR_UNEXPECTED`/`ENGINE_CRASH_UNEXPECTED`;
- tool/probe lines for the pseudo-scripts `__godot_export__`/`__godot_export_missing__` (ANSI + `[`-prefixed) exempt;
- else `FOREIGN`.
- pin rule: `signature in output` is a **substring test** (`run_battery.py:1808`); list signatures = alternates (any element); rows carrying `export_artifact` skip the pin test.
