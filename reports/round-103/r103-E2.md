## 4. Defect found (pre-fix) — xdg arm was non-hermetic; fixed in the fixture

Pre-fix recon run #2 of the xdg arm failed against the same root:

```
FAIL export_div s02 arm=xdg reason=run4_read_not_none:[run4] r3_read=none r3_exit=0 store_b=[run3] store_b_under_xdg=true r3_userdir_under_xdg=true r4_read=run4 r4_exit=0 store_c=[run4,run4] r4_userdir_under_home=true xdg_a_store=[run1,run2] proj=/var/tmp/r103c-E2v/root/div_s02/proj   (xdg2.out, sha256 73fefdc4…15b, rc=1)
```

Not an isolation failure: run3/run4 receipts were still correct; the arm's own setup wipe let state leak. Root cause (inference, from the two observations below): `_wipe_dir` listed entries via `DirAccess.get_directories_at` / `get_files_at`, which skip dot-entries, so `homeC/.local` survived the wipe and run4 saw the previous run's store (`run4,run4`).

Observation A — API probe on this exact engine (`/var/tmp/r103c-E2v/probe_api.gd`, dir holding `.hid/inner`, `vis`, `.hf`):

```
A_dirs_at_default=["vis"]   A_files_at_default=[]   B_dirs_instance_default=["vis"]   B_files_instance_default=[]   C_dirs_include_hidden=[".hid","vis"]   C_files_include_hidden=[".hf"]
```

Observation B — post-fix homeC shows exactly one `div_s02_state.txt` = `run4` after two xdg runs on the same root, and post-fix run#4 printed `r4_read=none` although pre-fix run#4 had left `run4` there (fix3/fix4 receipts).

Fix applied to `corpus/fixtures/export_div_s02.gd` (`_wipe_dir`, line-pair; this seat owns export_div*.gd):

```
-	for d in DirAccess.get_directories_at(dir):
-		_wipe_dir(dir.path_join(d))
-	for f in DirAccess.get_files_at(dir):
-		DirAccess.remove_absolute(dir.path_join(f))
+	var d := DirAccess.open(dir)
+	if d == null:
+		return
+	d.include_hidden = true
+	for sub in d.get_directories():
+		_wipe_dir(dir.path_join(sub))
+	for f in d.get_files():
+		DirAccess.remove_absolute(dir.path_join(f))
```

plus a comment block above it recording the probe numbers. Post-fix file: 468 lines, sha256 c08792c1c208d47a8af66c669e7296eb6a1d94fe3d20872aeb73d4d6620a4898 (identical in repo and in the harness copy). The hidden-entry guarantee matters because the xdg arm's whole payload lives under `homeC/.local`; every other wiped tree in this fixture is dot-free except `homeA/.local`, which is asserted absent rather than wiped.

## 5. Adversarial replay (scratch copies / real bytes only)

Receipt substitution, run inline over the post-fix logs (no new repo files): feed the real run4 USERDIR (`…/homeC/.local/share/godot/app_userdata/ExportDivS02`) through run3's isolation predicate → `run3_userdir_under_xdg=False`, i.e. a build that ignored XDG_DATA_HOME would have hit the FAIL branch `run3_userdir_not_under_xdg`. Symmetrically, run3's USERDIR through run4's fallback predicate → `run4_userdir_under_home=False` → `FAIL run4_userdir_not_under_home`. Both predicates therefore have teeth on real receipt bytes. Live-FAIL proof exists too: the pre-fix `run4_read_not_none` FAIL above shows the verdict machinery can and does emit FAIL, not only PASS.
