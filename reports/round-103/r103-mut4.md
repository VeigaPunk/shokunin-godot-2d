## Attack class (what must be rejected)

`r103-crit1` (seat C1-d): "header census echo (echoed rather than probed)" — a census arm that
reports header fields by echoing the bytes it just read (or constants copied from a genuine run)
and never binds the report to the presented artifact, so a tampered artifact inherits a
genuine-looking census. E4 (`export_div_s04`, PCK extended-header census) must REJECT it.

## Method (measured, not assumed)

1. Fresh minimal project (config name `Mut4Census`), preset `PCK` (Linux/X11) → real export
   `godot --headless --path proj --export-pack PCK out/div_m4.pck` (TMPDIR redirected to scratch).
2. E4-idiom GD probe `res://probe.gd` (`FileAccess.get_buffer` + `PackedByteArray.decode_u32/
   decode_u64`, struct-shaped) with two modes:
   - `valid`: computes its own validation booleans (magic/version/file_base/dir bounds/count/
     name-table walk/entry bounds) and judges `verdict=OK|REJECT reason=<clause>`;
   - `echo`: prints the same read-back CENSUS fields, NO judgment (`verdict=ECHO`) — the
     vulnerable shape under audit.
3. Seven byte-level forgeries of the genuine PCK; g5/g6 keep the header VERBATIM (echoed) and
   tamper only the body — the artifact-level header-echo shape.
4. Clause check over stored records + independent python oracle re-parse of the PRESENTED bytes:
   `A` bind_sha, `B` bind_bytes, `C` verdict_ok (VALIDATE all-true + verdict OK), `D` oracle_agree
   (read_ok AND field/entry equality). Ablations: `full=(A,B,C,D)`, `drop-bind=(C,D)`,
   `drop-oracle=(A,B,C)`.
