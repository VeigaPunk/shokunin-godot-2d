## Findings
* **F1 (pin-shape cliff, measured).** Echo-only / head pins re-open the phantom: on the real fixture `P_yecho` accepts all four forgeries; on the model `P_head_offy` accepts the no-op echo, the y-normalized line and the key swap. Full-line pins reject all of them in both rigs, and ver8's staged C pin rejects all four Rig-C forgeries while the current x0-shaped pin accepts two of them.
* **F2 (omit forgery is the sharp edge, measured).** Dropping the physics-bound keys makes real and no-op physics **byte-identical** (Rig A) — `P_noevid` cannot discriminate; same structure in Rig C: `c_omit_y` (a "fixed" fixture that normalizes y) is x0-shaped and passes every x0-era pin, rejected only by `C_expected`. Any C3 pin must therefore *contain* y-binding bytes (`1000.0000` in a relpos/absy column, or `dy_resid=0.0000`/`n_at_0=0` in the new fixture), and must be the **full** line if tail tampering is to reject.
* **F3 (order-swap caught iff spanned, measured).** Key swaps are rejected by full-line and by Rig-C C_expected pins, accepted by echo/head/key-subset pins (`mut_swapkeys` × `P_yhead`/`P_yecho`/`P_ykey`/`P_yabsy` = PASS).
* **F4 (cross-line pins bite line omissions, measured).** Rig B `m5_noenv` passes every single-line pin and is rejected by the multi-line `P_pair` — a signature containing a newline is a contiguous-substring test. Corollary (inference, not run): single-line pins are insensitive to line order by construction; diag lines are unpinned by both fixtures' contracts.
* **F5 (half-landings go red, measured).** Either half of ver8's staged pair without the other fails its own row (`c_committed` × `C_expected` = FAIL; `c_base` × `cur_y1000` = FAIL), so the pair is self-guarding against a split integration — loud, not silent. For E17's fixture the same holds trivially: no rows exist, so nothing regresses until rows are landed (and r100-critic F1 says a *dropped* row is invisible — prior measured art, not re-run here; battery forbidden).
* **F6 (substring aliasing — hygiene, inference from a measured PASS).** `t2_absy=[1000.0000|…]` also matches inside `b_t2_absy=[1000.0000|…]` (base_ycop × P_yabsy = PASS). Bare-key pins are not arm-scoped; only full-line pins (or the leading `PASS r101_ytrans <arm>` token) are. Latent, not exploitable with one row per arm.
* **F7 (environment, observation).** One tmpfs receipt anomaly: `out/m2_omitkey.rc` read 0 B (all others fine, stdout complete). One rerun gave rc=0, same 1138 B stdout; classifier falls back to `run_log.txt` and says so. Same /tmp-pressure class r100-critic documented.
