## 1. How the census scanner finds the new fixtures (source-cited)

| step | mechanism | location |
|---|---|---|
| fixture file reaches scratch | **whole-directory copy** of `corpus/fixtures/` into `run_dir/scratch` | `run_battery.py:1675-1681` |
| fixture is executed | only if a `CASES` tuple names it: `godot --headless --path scratch --script res://<script>` | `run_battery.py:2303`, `1862` |
| row becomes a `results` record with an allowlist | `record["expected_errors"] = list(expected_errors)` | `run_battery.py:2296` |
| allowlist source | one hardcoded dict **keyed by case name** inside `execute()`, applied only under `if passed is None:` | `run_battery.py:1968-1971` (+ `.get(name, ())`) |
| census scope | `for row in results: entries = row.get("expected_errors") or []; if not entries or not isinstance(row.get("output"), list): continue` | `run_battery.py:3663-3707` |
| dead count | `len([entry for row for entry if entry["dead_in_run"]])` | `run_battery.py:3704-3707`, `3731` |
| per-round floor | `all(not e["dead_in_run"] for r in census_rows if r["case"].startswith(prefixes) …)` | `run_battery.py:3877-4014` |
| vacuity guard | `cases_integrity`: uniqueness + non-empty existence per pinned prefix | `run_battery.py:4022-4027` |

**Load-bearing consequence (observation):** the census never globs the fixtures
directory. A `export_prod_s*.gd` file with no `CASES` tuple is copied into scratch and
then never executed, never recorded, never censused. File presence is necessary but
**not sufficient**; `CASES` registration is the only discovery predicate. The
`cases_integrity` existence check is what stops a per-round gate from being vacuously
true over zero rows.

Second scanner ceiling (observation, `ver12_census_live.py` scenario
`sentinel_path_row` → `census_rows=0`): rows resolved by the export sentinel
(`__godot_export__` / `__godot_export_missing__`, `1863`) set `passed` before the
allowlist dict is consulted (`1968`), so their `expected_errors` is forced to `()`.
**A new export-family row must be a plain script row (`export_prod_s*.gd`), not a
sentinel row, or it can never carry an allowlist entry.**

Third ceiling (observation): entry-less rows are outside the census entirely
(`if not entries … continue`), so the floor can only be claimed for rows that declare
entries. A row with a signature-only pin contributes nothing to `dead_entry_count`.

- **Observation (measured 16:29Z, load `37.61 42.89 28.17`), nested-export cost:** the

  godot --headless --path . --export-release "Linux/X11" out.x86_64 rc=0 wall_ms=2215  artifact_bytes=73519416

  prefix-aware timeout in `execute()` (shared file — not touched by this seat). The
  release artifact is **73.5 MB** per export (template embed); ~12 rows that do not
  delete their outputs would write ~0.9 GB into `corpus/live/runs/<stamp>`.
