## 3. Adversarial validation (forgery resistance of the pin)

**Forged replay line rejects.** Mutated copy of the fixture (scratch only, never the repo)
whose generated scene prints an extra `[s11] frame=99` after every real frame:
```
$ R101_E11_ROOT=/var/tmp/r101-E11/work-mut godot --headless --path proj-mut --script res://export_prod_s11.gd -- --arm=launch
FAIL export_prod_s11 launch reasons=receipt_mismatch evidence=got=["[s11] ready scene=main", "[s11] frame=1", "[s11] frame=99", "[s11] frame=2", "[s11] frame=99", …]
rc=2   fixture stderr=0 bytes
```
The `launch`/`ladder`/`alt_main`/`early_quit` arms compare the **whole ordered receipt
list** (`[s11] ready scene=<tag>`, `frame=1..N`, `exit frames=N`) for equality, so an
inserted, dropped, duplicated or reordered line all reject — not a substring check.

**Identity discrimination.** `alt_main` asserts `scene=alt` *and* the absence of
`scene=main`, so a pack that boots the wrong main scene (or a hardcoded receipt printer)
cannot pass.

**Exit-code trap closed.** `corrupt` requires rc 0 *and* the
`Cannot open resource pack` error class *and* zero receipts, i.e. the row's positive
sibling cannot be satisfied by a process that failed to open the pack.

## 6. Environment notes / hazards (observed)

- `/tmp` is tmpfs under heavy sibling-lane load and **quota-constrained**: `cp` of the
  73,519,416-byte export template failed at 70,795,264 bytes with
  `cp: error writing '…/tmpl-copy-test': Disk quota exceeded`, and
  `godot … --export-release "Linux/X11" out/main.pck` produced a truncated 53 MB ELF
  (`file`: "missing section headers at 73519352", runs → SIGSEGV 139) with
  `ERROR: Prepare Template: Failed to copy export template.` This is host pressure, not a
  Godot fault (mut5 §F4 reports the same class). Consequence for this scenario: it never
  copies a template (`--export-pack` only) and its scratch root is
  `EXPORT_PROD_ROOT/s11` → `R101_E11_ROOT` → `user://r101e11` — never `/tmp` by default.
- The fixture leaves only the small cache (packs + stamps, a few KB) under the chosen
  root; per-launch capture files are purged before every spawn (stale-evidence rule),
  `--keep` preserves everything, `--clean` removes the whole root at exit.
- Failure exit code is 2 (repo-dominant assertion convention, 222 uses in fixtures);
  `--fail-exit=N` overrides it. Note the lead's `export_prod.gd` uses 1 for its
  operational failures — flag if the lattice should be uniform.
- `_pack_guard()` parses the measured pack v4 layout (magic/version/file_base/dir_offset,
  `count(4)` then `path_len(4) path offset(8) size(8) md5(16) flags(4)`), validated
  independently against a Python parser (all entry md5s OK). A future format change
  fails closed (`pck_dir_offset` / `pck_entry_path_len` / `pck_project_binary_bytes=0`).
