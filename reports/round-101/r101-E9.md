## 2. Measured mechanisms (each cited with the command that produced it)

**M1 — `res://.godot/exported/` must pre-exist, or the export silent-fails with a 0-byte pack.**
First export of a brand-new project: `godot --headless --path /tmp/r101-E9/nested --export-pack "Linux/X11" /tmp/r101-E9/out/nested.pck`
→ `rc=0`, log ends `[ DONE ] savepack`, and yet `out/nested.pck` = **0 bytes**, with
`ERROR: Unable to save export scene file to: res://.godot/exported/133200997/export-…-level_deep.scn` +
`at: _export_customize (editor/export/editor_export_platform.cpp:1096)`.
After `mkdir -p <proj>/.godot/exported` the same command wrote **4136 bytes** (rc=0). The fixture creates that directory in `_write_project()`.

**M2 — PCK v4 header + directory table (byte-exact census API).**
Parsed from `out/nested.pck` (4136 B) and `…/s09.pck` (4280 B):
`magic "GDPC"` · u32@4 `pack_format=4` · u32@8/12/16 `4.7.2` · u32@20 `flags=2` · u64@24 `file_base=112` · **u64@32 `directory_offset`**; at that offset: `u32 count` then per entry `u32 pathlen, path, (pad4), u64 offset, u64 size, md5[16], u32 flags`. Parsing consumed the pack exactly to EOF (`off == size`) for both packs, and `file_base + max(off+size) <= size` held.
**Directory paths are NUL-padded and the stored length is the padded length** (measured `project.binary\x00\x00`, `scenes/main.tscn.remap\x00\x00`). Decoding them with `get_string_from_utf8()` yields U+FFFD and prints `Unicode parsing error, some characters were replaced with … Unexpected NUL character` (3 such lines per run), and `.ends_with(".gdc")` then misses 2 of 3 compiled scripts (measured: `gdc=[665]` instead of `[190,210,665]`, `dot_n=4`→ mis-set). The fixture therefore trims trailing `0x00` **on the bytes** before decoding.

**M3 — child stdout markers are split by ANSI escapes.**
Captured export stdout contains `\x1b[92m[ DONE ]\x1b[39m\x1b[1msavepack`, so `text.contains("[ DONE ] savepack")` is **false** on the raw string (first fixture run failed exactly there: `export attempt 1 rc=0 no savepack marker`, wall 3199 ms). The fixture strips `\u001b\[[0-9;]*m` before matching.

**M4 — the export is reproducible for a fixed fresh project, but was NOT while editing the scratch sources.**
- Fresh-project rebuilds of the shipped fixture project: **8/8 identical** — 4280 bytes, `pck_sha256=c6af7bbb8deca38ecc49909c6875053c6b071c76024e0b042340a58c4bf33f6f` (census, both, sensitivity, 3× rep, default, final sweep).
- Hand-iterated project (`/tmp/r101-E9/nested`, sources edited between exports): 3 distinct packs — `fca281e6…` 4136 B, `9940b4fc…` 3960 B, then `039122a3…` 4136 B byte-stable for 10 consecutive exports. Entry *sets* were identical in all three; the 4136/3960 delta is only `project.binary` (176 B vs **0 B**), and the `fca281e6→039122a3` delta is 40 bytes inside the two exported `.scn` files (uid-bearing fields, 4 bytes each) that settled after the first uid-assignment pass.
⇒ Never treat a first-export-after-edit pack as reproducible, and never pin `.scn` md5/uid bytes.

**M5 — a structurally valid pack can be unbootable: the 0-byte `project.binary` glitch.**
Observed 1/13 exports of the iterated project: entry list identical, pack 176 B smaller, export `rc=0` with a clean `[ DONE ] savepack`. Launching it (`godot --headless --main-pack out/repro2.pck --quit-after 3`) produced **no receipt line**, 372 B of output, containing
`ERROR: Corrupted header in binary project.binary (not ECFG).` / `at: _load_settings_binary (core/config/project_settings.cpp:918)` and
`ERROR: Couldn't load file 'res://project.binary', error code 16.` / `at: _load_settings_text_or_binary (core/config/project_settings.cpp:1004)`.
A census alone cannot see this (entry names/sizes of everything else are unchanged); the run receipt does. The fixture exports up to `MAX_EXPORTS=3` times while `project.binary` is empty and prints the retry count in the tail diagnostic.

**M6 — `export_filter="all_resources"` packs even an unreferenced 3-deep script.**
`cp -a` of the built project + new `scripts/core/deep/extra.gd` (referenced by nothing) + fresh `.godot` + export → pack grew 4280 → **4660 B**, count 13 → **15**, `scripts/core/deep/extra.gdc` (123 B) and `extra.gd.remap` (50 B) present. This is the sensitivity arm's basis.
