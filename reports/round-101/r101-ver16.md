## §3 Findings

**F1 (observation) Sequential exports from a fixed project state are byte-identical.** 8–15 consecutive equal runs per state (a-state 8/8, b-state 15/15 plus z/e/r/c/d). Path relocation (`cp -a` to `projcopy`, export `c1`) and source-`touch` (`d1`, `e1`) did not change bytes: exports are absolute-path-independent and mtime-independent.

**F2 (observation) The only within-state run-to-run variance is the `project.binary` entry going empty.** a-state: 2/12 runs packed `project.binary` at 0 B (a1, a3); b-state: 3/6 in one cluster (t_badtmp, t_goodtmp, t2). All other 11 entries byte-identical; total 3496→3240 (`project.binary` 251→0) and header `dir_off` (@0x20) 2640→2384. Exit code 0, empty stderr, log still says `Storing File: res://project.binary`.

**F3 (observation, strace) The packed settings are serialized through a fixed host-global temp path.** `strace` of one export:
```
openat("…/proj/project.binary", O_RDONLY) = -1 ENOENT
openat("/tmp/tmpproject.binary-bWllwE", O_RDWR|O_CREAT|O_EXCL, 0600) = 9
rename("/tmp/tmpproject.binary-bWllwE", "/tmp/tmpproject.binary") = 0
openat("/tmp/tmpproject.binary", O_RDONLY) = 9
unlink("/tmp/tmpproject.binary") = 0
```
`TMPDIR=/nonexistent` is ignored — the same literal `/tmp/tmpproject.binary*` sequence appears. The path is shared by every Godot export on the host (all seats/lanes).

**F4 (causal proof) Empty `project.binary` is an environmental failure, silently swallowed.** In a private mount namespace (no host impact) with `/tmp` mounted as a full 64K tmpfs: export rc=0, stderr empty, PCK sha16 `e86eed075c4fcd82` — byte-identical to the wild 0-variant cluster (F2). Same setup for ZIP: rc=0, but the output `.zip` is **0 bytes** (corrupt). The host's real `/tmp` quota exhaustion is the cause of the in-the-wild 0s; the successful `t3–t7/s1` runs coincide with 251-byte `/tmp` probe successes.

**F5 (observation + inference) Cross-export contamination surface.** Because the temp path is host-global and fixed (F3), two concurrent exports can in principle exchange settings. 8 concurrent A/B pairs (distinct project names) → 16/16 packed their own name, correct 247-byte ECFG, none empty. Contamination not observed in 16 trials; the race window exists by construction (inference), and rows must not add load to it.

**F6 (observation) Export bytes depend on the import state, not just sources.** After `rm -rf .godot` + re-import, 5/5 runs are byte-stable but at a different sha (`dd1695bb…` vs `088e908a…`). Entry-level diff of a10 vs b1: only the two `.godot/exported/…/*.scn` payloads differ — same size (669 B), **4 differing bytes in one contiguous run at payload offsets 493–496** (a10 `…d6e87400…`, b1 `…29847e00…`), while `uid_cache.bin`, `global_script_class_cache.cfg`, `project.binary` are identical. So the scene export embeds a small per-import-state id (inference: resource id assigned on import; mechanism not further pinned).

**F7 (observation) Container facts the rows may lean on.** PCK: magic `GDPC`, version 4 (4.7.2), flags=2 (relative file base), `data_off`=112, 72 reserved zero bytes, directory table at the tail (`dir_off`), per entry `u32 path_len` (path padded to 4, length includes padding), path, `u64 off`, `u64 size`, 16B md5, `u32 flags`; table consumes exactly to EOF (trailing=0 on all 45). ZIP: entry timestamps fixed `1980-00-00 00:00` (no wall-clock, no mtime dependency); central directory lists the same 12 entries. Full binary with `embed_pck=false` == template bytes.

## §4 RULES — binding invariants for any row that pins export bytes

- **R1 — Whole-file sha256 is admissible only in a settled state.** Prereqs: ≥1 warm-up export discarded; ≥2 consecutive exports in the same project state byte-equal; `project.binary` non-empty in every compared run; no other Godot export process concurrent on the host. Else the row must not use whole-file sha.
- **R2 — Otherwise pin per entry.** Parse `data_off`(@0x18)/`dir_off`(@0x20)/count and assert `(path, size, md5, sha256)` for each of the 12 entries; assert `dir_end == file_size` (trailing 0). Exclusions must be an explicit named census with observed bounds (§5) — never a silent skip.
- **R3 — Empty `project.binary` is a hard FAIL, never an allowed variant** (F4). Fail closed (negative test: a row must reject the 0-byte artifact).
- **R4 — Content-pin `project.binary`.** Assert ECFG magic and the row's own `application/config/name` inside it. This catches both R3 zeroes and any cross-project contamination (F3/F5), which a hash-pin of a contaminated-but-self-consistent pack would not.
- **R5 — Header pins must be relational, not absolute.** Pin magic/version/flags/reserved-zeros; `dir_off` must equal `file_size − dir_size`; do not pin absolute `dir_off`: a `project.binary` size change shifts it (2640↔2384 observed).
- **R6 — ZIP rows.** Settled-state whole-file sha is admissible (timestamps fixed 1980, mtime/path-independent observed), but the row must also fail closed on 0-byte/unparseable output (observed `nsz.zip`: rc=0, 0 bytes) and assert the central-directory entry count; `project.binary` inside the zip stays content-pinned (R4).
- **R7 — Binary rows.** With `embed_pck=false` the exported executable is byte-identical to the template (F7); pinning its sha is content-free. Project-payload evidence must come from the sidecar `.pck`.
- **R8 — Environment admissibility.** A determinism evidence run requires a writable `/tmp` at run time; record a probe (e.g., 1 KiB write to `/tmp`). `TMPDIR` is not a workaround (F3). Two runs that both carry the F4 failure must not count as "equal" (R3 fails first).
- **R9 — Do not compare `.scn` bytes across independently imported trees** without bounding the id field (observed: 4 contiguous bytes at payload 493–496 for this scene shape); within one tree they are stable (F1/F6). Comparing different scratch trees built from the same sources is only admissible per-entry with that exclusion.
- **R10 — Serialize.** Byte pins must be produced when no other Godot export runs; concurrent evidence (or evidence taken under `/tmp` pressure) must be labeled inadmissible for determinism.
