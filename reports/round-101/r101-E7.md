## Discrimination (why a forged single line cannot pass this row)

- D1 **exact bytes, not substring**: `sparse_unknown` contains the canonical R1 substring yet is a distinct 788 B string; the classifier rejects it. This is the r100-critic F2 lesson applied to error classes.
- D2 **name echo**: name_swap mutant (`Linux/X11` line under a `NoSuchPreset` request) rejected by stderr equality.
- D3 **census certificate**: the refusal lists the project's real preset census parsed from the cfg; census_spoof (list edited) rejected.
- D4 **conjunction**: rc must be 1, stderr exact, artifact absent, stdout without `savepack`. rc_forged, artifact_forged and control_splice (real successful run's stdout + spliced refusal stderr) are each rejected on a different conjunct.
- D5 **adjacent-name control**: a preset named `NoSuchPreset` exports — a harness that only string-matches the token cannot explain rc=0.
- D6 **precedence**: unknown+no-path is byte-identical to unknown+path; known+no-path is the R5 class (rejected by the R1 classifier despite rc=1).
- D7 **empty name is not a refusal**: `--export-release ""` never emits R1, never packs, and idles until the harness bound kills it (rc 124 over both 40 s and 180 s bounds).
- D8 **mode stability**: `--export-debug` and `--export-pack` produce the identical R1 bytes, so the row is not release-only.

- Added: `out/` is wiped at start so a stale artifact from a previous run cannot satisfy a later check.
