## s01 expected values — standalone PCK (derived, layout from source 2)
Header (little-endian), all offsets from file start:

| off | size | field | expected value |
|---|---|---|---|
| 0 | 4 | magic | `47 44 50 43` = ASCII `GDPC` = u32 0x43504447 | 
| 4 | 4 | pack format version | `04 00 00 00` (V4) on 4.7.2; 2 ≤ v ≤ 4 legal per reader, fixtures should expect 4 |
| 8 | 4 | engine major | 4 |
| 12 | 4 | engine minor | 7 |
| 16 | 4 | engine patch | 2 |
| 20 | 4 | pack flags | default `0x00000002` (REL_FILEBASE only); `|0x1` if dir encrypted, `|0x4` if sparse |
| 24 | 8 | file_base | offset of first file = pck_start + 112 for standalone (104-byte header padded to 16) |
| 32 | 8 | dir_offset | 16-aligned offset of directory |
| 40 | 64 | salt/reserved | zeros (salt only when enc+sparse) |
| 104 | 8 | padding | zeros to first 16-byte boundary (104→112) |

Data region: files stored in ascending path order (writer sorts `file_ofs`), each file's bytes padded so the next file starts on a 16-byte boundary. Directory at `dir_offset`:
`u32 count` then per entry: `u32 (len + pad4(len))`, path UTF-8 bytes, zero padding, `u64 offset` (relative to file_base), `u64 size`, `16 md5` (MD5 of the exact stored bytes), `u32 flags`.

- **Exact size formula:** `T = dir_off + 4 + Σ_i(40 + ceil4(len_i))` where `dir_off = ceil16(112 + Σ_i(size_i + pad16_after))`, each file block padded to 16.
- **Bounds (n files):** `112 + Σ size_i + 4 + 40n ≤ T ≤ 112 + Σ(size_i + 15) + 4 + Σ(40 + len_i + 3)`. For the scratch rig: n=7, T_obs=1928 (see observation).
- **No trailing footer** standalone: T == dir_off + dir_size exactly; the `u64 size`+`u32 magic` footer exists only for embedded PCK (`save_pack(..., p_embed=true)`, writer lines 2359-2369). A fixture that finds `GDPC` at EOF+(-... ) or size beyond dir_end is looking at an embedded artifact.
- **Census caveat:** the packed file set is the *exported* set, not the on-disk set — `project.godot` is replaced by `project.binary`, scripts become `.gdc` with `.gd.remap`, scenes become `.godot/exported/<id>/export-<hash>-<name>.scn` with `.tscn.remap`, plus `.godot/uid_cache.bin` and `.godot/global_script_class_cache.cfg`. Observed 7 entries for a 4-file scratch project. Count/size rows must derive from that set.

## s02 expected values — zip (derived, ZIP source 3 + writer 2)
- Byte 0..3 = `50 4b 03 04` (`PK\x03\x04`, first local file header), not `PK\x05\x06`.
- Each file → one local header (`PK\x03\x04`) + one central-directory header (`PK\x01\x02`) + one EOCD (`PK\x05\x06`) at the very end: EOCD is the **last 22 bytes** when `comment_len = 0` (Godot calls `zipClose(zip, nullptr)`; observed comment len 0).
- EOCD fields: `entries_total` u16 @+10 = packed file count; `cd_size` u32 @+12; `cd_offset` u32 @+16; consistency `cd_offset + cd_size + 22 + comment_len == filesize`.
- CD header layout: sig +4 `version_made_by` u16, +6 `version_needed` u16, +8 flags u16 (bit 11 UTF-8 name set by writer for folder path; file entries from minizip defaults), +10 method u16 (8 = deflate), +12 DOS time u16, +14 DOS date u16, +16 CRC32 u32, +20 csize u32, +24 usize u32, +28/+30/+32 name/extra/comment lens, +42 local header offset u32, +46 name.
- **Timestamp field expectation:** writer passes `nullptr` zip_fileinfo for exported files, so DOS time/date are **0x0000** (observed in run1.zip local header: `... 0800 0000 0000 ...` method=8, time=0, date=0; `unzip -l` renders `1980-00-00 00:00`). Fixture should expect zero, not wall-clock.
- Census invariants a fixture can pin: entry names = packed file set (same as s01 census); every CD entry's local header name matches its CD name; method 8; CRC32 recomputed from the deflate payload matches; no Zip64 records for small projects (no `0xFFFFFFFF` sentinels, `entries_total < 0xFFFF`).
- Note the *bare* deflate stream: minizip uses `Z_DEFAULT_COMPRESSION`; small/incompressible payloads may be emitted as stored blocks inside the deflate wrapper (observed `01 27 01 d8 fe` = stored block for main.gdc); parse with raw deflate (`zlib.decompress(data, -15)`).

## s03 expected values — determinism sha256 ×2
- PCK V4 has no wall-clock or environment fields (no timestamps; paths relative to pack; MD5 = data digest). Expectation: byte-identical sha256 across two exports of an unchanged project (matches mut5 observation `b90fad33…` ×2). Only `.godot` cache drift between runs changes bytes.
- ZIP from `--export-pack` has zero DOS timestamps (see s02) → expected byte-identical too; the wall-clock path `zip_folder_recursive` (sets current OS date/time) is used for bundle resource zips, not for `--export-pack` file entries.
- Determinism still needs the *same exported file set*: a re-import between exports can change `.godot/uid_cache.bin` or the exported `.scn` (different `<id>` dirs, see F-hazard below) and legitimately changes bytes. Fixtures must import once, then export ×2.
- Encryption/sparse presets change flags and salted IV derivation (`RandomPCG(seed)` from content) — out of scope for s01–s03 defaults.
