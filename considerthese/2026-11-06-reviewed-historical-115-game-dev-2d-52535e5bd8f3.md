# Intensity changes are not object meanings

Marr and Hildreth’s [edge detection theory](https://www.hms.harvard.edu/bss/neuro/bornlab/qmbc/beta/day4/marr-hildreth-edge-prsl1980.pdf), 1980, Abstract and Introduction, separates describing intensity changes from interpreting them.

Canny’s [edge detection approach](https://www.cs.princeton.edu/courses/archive/fall13/cos429/papers/Canny86.pdf), 1986, Abstract, Introduction and §V, distinguishes detection, localization and single response. Directional detection differs from the earlier Laplacian approach in two dimensions despite their close relationship in one dimension. Neither model guarantees semantic object boundaries or establishes a universal quality ranking.
