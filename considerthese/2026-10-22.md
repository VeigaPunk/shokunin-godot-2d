## Top 3 lessons / gains in the window

### 1. Physics replay tests assert invariants, not digests
[7d9d974](https://github.com/VeigaPunk/shokunin-godot-2d/commit/7d9d97414063f7d836a00ff730ad23872a65fccd) added `corpus/fixtures/r105_phys_replay.gd` and `corpus/knowledge/2026-10-19-physics-replay-boundary.md`. On this host and build (Godot 4.7.2, headless, Godot Physics 2D), a scripted scene with 8 RigidBody2D boxes and a CharacterBody2D replayed bit-identically across 20 serial runs with and without `--fixed-fps`. A 1e-4 px perturbation arm changed the digest on 4/4 runs, which proves the digest is not vacuous.

The lane still refuses to pin that digest, because the Godot docs say physics is not deterministic and godotengine/godot#112976 shows divergence with 3 or more moving bodies plus `_process`-timed scene reloads. The decision recorded: replay tests check body counts, boundary containment and speed bounds, record the digest as evidence only, never retry until match, and every digest fixture carries a perturbation negative control.

Lesson: an observed host property is evidence, not a contract. Gates encode only what the engine guarantees.

### 2. `uid://` resolution at runtime depends on the binary cache, not the `.uid` sidecars
`corpus/knowledge/2026-10-19-res-uid-runtime-authority.md` (same commit) restores the UID rows r104 had to retire, now run in fresh scratch projects with per-run `XDG_DATA_HOME` isolation. Findings: a plain `--script` process resolves nothing once `res://.godot/uid_cache.bin` is deleted, even with `.uid` sidecars present. The `uid://` text is a lossy spelling (`uid://`, `uid://a` and `uid://aaaa` all parse to id 0, and `uid://z` equals `uid://0`). Two sidecars with the same id leave exactly one cache record and a single editor warning.

Decisions recorded: compare UIDs by integer id, never by string; run an `--import` pass before scripted tests on a fresh checkout; test misses with `has_id()` because `path_to_uid()` echoes its argument; and treat `UID duplicate detected` warnings as blocking.

Lesson: this is practical, shippable Godot 2D knowledge (CI on fresh checkouts and merge conflicts in `.uid` files), and it came from fixing the r104 isolation bug instead of dropping the rows.
