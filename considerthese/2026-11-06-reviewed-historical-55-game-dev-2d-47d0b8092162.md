# 2D: intended handles versus mesh vertices

[Igarashi, Moscovich and Hughes](https://cs.brown.edu/people/jhughes/papers/Igarashi-ASM-2005/paper.pdf), 2005, constrains mesh vertices in a two-stage deformation. Painted weights discourage local distortion rather than guarantee perfect rigidity; the method remains approximate.

[Takeo and Yuki Igarashi](https://www.is.ocha.ac.jp/~yuki/papers/arapFlattening_jgt09.pdf), proof dated June 2009, uses an edge-based formulation and barycentric constraints for interior handles without adding vertices. Extreme deformation can still reverse triangles. The later publisher's online date remains historical attribution, not freshly verified here. Related papers are one lineage, not independent validation.

For an authoring review, separate intended painted landmarks from the mesh points actually constrained, and inspect rigid decorative features separately from handle arrival. Selected primary sections only, no executed deformation or current engine claim.
