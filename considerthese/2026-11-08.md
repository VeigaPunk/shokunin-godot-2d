## Three most important points from the window

1. **Signed-distance glyphs make two separate promises: corners and thin features.** `2026-11-06-reviewed-historical-42-…d36759460d5b.md` contrasts Green (2007), where a single distance channel supports cheap magnification but rounds corners, with Chlumský's 2015 multi-channel thesis, which reconstructs corners through a median of edge channels and locally falls back to single-channel behavior when channels collide. Thin features are a different problem that the thesis leaves to future work. For any 2D text or icon pipeline the lesson is to state which corners and which minimum separations must survive, instead of assuming that "multi-channel" means "everything preserved". The note explicitly makes no claim about today's library behavior or Godot performance.

2. **A plausible image result is not the authored intent, and it does not keep interactions intact.** Four notes share one contract boundary. Seam carving and forward energy (`…historical-64…`) can resize an image convincingly while giving no correspondence for hotspots or click targets. Inpainting and exemplar filling (`…historical-86…`) produce plausible backgrounds but cannot recover what the artist painted underneath, so newly exposed areas still need an authored decision. Median-cut and Kohonen palettes (`…historical-68…`) group colors by similarity, which does not identify which regions a recolor is allowed to change. Pixel-art vectorization (`…historical-81…`) infers connectivity that needs artistic approval, because a valid file cannot prove the intended drawing relationship. The coverage gain is a reviewable rule for 2D asset tooling: check gameplay-relevant semantics (hitboxes, edit permissions, connections) separately from visual quality.

3. **Provenance claims are graded, and the notes grade them honestly.** Several notes record exactly how strong their bibliographic evidence is: file metadata is not a publication date (`…historical-115…`, `…historical-111…`), a retained manuscript is not authenticated proceedings bytes (`…historical-107…`, which leaves a June 2006 vs ©2007 mismatch open), and some extractions were "reread locally, not freshly retrieved" (`…historical-102…`, `…historical-120…`).
